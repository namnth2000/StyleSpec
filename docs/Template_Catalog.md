# Template Catalog

## 1. V2.x catalog

V2.x is implemented with 18 templates across 6 domains. The catalog prioritizes breadth of design direction instead of accumulating color variants.

## 2. Tool / Utility

### 2.1 Northstar - Soft Utility

Giữ lại direction hiện tại để migration từ V1.

- Top navigation
- Marketing-style hero
- Primary + Secondary CTA
- Soft cards
- Spacious layout
- Rounded visual language

Northstar chỉ là một lựa chọn, không còn là universal preview.

### 2.2 Workspace

- Sidebar navigation
- Không cần hero
- Workspace xuất hiện ngay ở first fold
- Dense information layout
- Actions nằm trong toolbar hoặc inline control
- Phù hợp productivity tool, editor, dashboard

### 2.3 Editorial Tool

- Minimal navigation
- Intro text ngắn ở một bên
- Interactive tool chiếm phần lớn viewport
- Asymmetric layout
- CTA có thể là inline action thay vì hero button
- Phù hợp calculator, converter, creator tool

## 3. Software / SaaS

### 3.1 Product-first

- Product screenshot hoặc interactive mockup là focal point
- Copy hỗ trợ sản phẩm thay vì chiếm toàn bộ hero
- CTA gọn
- Sections xoay quanh product proof
- Phù hợp SaaS, desktop app, mobile app

### 3.2 Technical Console

- Docs-like navigation
- Mono accent hoặc code-oriented typography
- Command, code sample hoặc technical artifact xuất hiện sớm
- Dense layout
- CTA có thể là Install / View docs / Try command
- Phù hợp developer tool, API, infrastructure product

### 3.3 Narrative Launch

- Full-screen hoặc cinematic opening
- Scroll theo narrative sequence
- Ít card grid
- Section transition bằng image, background hoặc large type
- Phù hợp launch page, product story, new feature release

## 4. Portfolio

### 4.1 Project Index

- Không cần hero truyền thống
- Tên hoặc intro rất ngắn
- Project list hoặc index là nội dung chính
- Typography và spacing tạo hierarchy
- Phù hợp developer, designer, photographer

### 4.2 Case Study Grid

- Project thumbnails là first-class content
- Grid có thể asymmetric
- Mỗi project dẫn vào case study
- CTA cá nhân giảm xuống vai trò phụ
- Phù hợp designer, studio, agency cá nhân

### 4.3 Personal Editorial

- Intro giống opening của magazine/editorial
- Kết hợp serif + sans hoặc typography có contrast
- Content rhythm theo article
- Links và text hierarchy quan trọng hơn cards
- Phù hợp writer, creator, consultant

## 5. Wedding

### 5.1 Editorial Invitation

- Invitation-first
- Typography và whitespace là focal point
- Không dùng SaaS CTA hierarchy
- Section có thể là ceremony, story, schedule, RSVP
- Phù hợp wedding site tối giản, thanh lịch

### 5.2 Paper Collage

- Layered paper motif
- Overlap có chủ đích
- Photo, botanical hoặc decorative cutout
- Section transition có chiều sâu
- Phù hợp handmade, vintage, romantic direction

### 5.3 Photo Journal

- Photography-first
- Full bleed hoặc large image sequence
- Text ngắn đóng vai trò caption
- Story timeline hoặc album rhythm
- Phù hợp wedding site có bộ ảnh mạnh

## 6. V2.x implemented batch - Game + Blog / Editorial

Hai domain này được thêm trong cùng một batch. Domain chooser tăng từ 4 lên 6 lựa chọn, đồng thời catalog có thêm hai cực rất khác nhau: interaction-heavy Game và content-heavy Blog / Editorial.

Mỗi domain implement đúng 3 direction. Không thêm direction thứ tư cho đến khi 6 direction mới đã được đánh giá trong UI thật.

### 6.1 Game

Game là domain ưu tiên vì composition khác xa generic SaaS.

#### Arcade Cabinet

- Game viewport hoặc poster là focal point
- Strong display type
- Score / mode / play action
- High-energy composition
- Có thể mở trực tiếp vào play surface thay vì marketing hero

#### Cinematic Game

- Full-screen artwork
- Minimal chrome
- Story, trailer, character hoặc world sections
- Large media transition
- Copy đóng vai trò hỗ trợ atmosphere thay vì dẫn toàn bộ hierarchy

#### Retro Console

- Pixel / terminal / console-inspired structure
- Compact UI
- Strong state and interaction motif
- Menu, status hoặc game metadata là một phần của composition

`Toy Box` giữ làm candidate sau này thay vì đưa vào batch đầu.

### 6.2 Blog / Editorial

Blog / Editorial phải ưu tiên reading hierarchy, typography và content rhythm. Không biến blog thành landing page có hero + CTA + card grid.

#### Publication Index

- Masthead hoặc publication identity rõ ràng
- Article index là nội dung chính ngay từ first fold
- Dense nhưng có hierarchy rõ qua typography, metadata và rules
- Có thể dùng multi-column hoặc newspaper-inspired grid
- Không cần CTA chính

#### Longform Journal

- Một featured story hoặc article opening là focal point
- Reading width, large editorial type và whitespace dẫn composition
- Media được dùng như part of narrative flow
- Section rhythm dài và yên hơn marketing page
- Phù hợp personal blog, essay, technical writing hoặc journal

#### Visual Magazine

- Image-first editorial composition
- Asymmetric hoặc modular grid
- Headlines, captions và imagery tạo hierarchy
- Có thể dùng cover-story treatment thay vì conventional hero
- Phù hợp culture, fashion, travel, photography hoặc creator publication

## 8. Quy tắc catalog

- Không thêm template chỉ vì có palette đẹp.
- Không thêm nhiều template cùng cấu trúc hero + two CTA + three cards.
- Thumbnail phải giúp phân biệt composition trước khi đọc tên.
- Mỗi domain nên có ít nhất một direction không dùng hero marketing truyền thống.
- Mỗi batch mới phải được review theo Template_Research_Guideline.md.
